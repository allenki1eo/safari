🔑 Runner recovery

For a player who lost their runner and never set a recovery PIN. Make sure it's really them first (for example, ask for a screenshot of their old score). The code works once, for 7 days: they open Settings → Get my runner back and type it in place of a PIN.

🔔 Notifications checking…

Notifications need a key pair. Make one here — it is created in this browser and never sent anywhere — then add it to Vercel:

  1. Tap Make notification keys.
  2. In Vercel → safari project → Settings → Environment Variables, add each value below under its name.
  3. Redeploy (Deployments → ⋯ → Redeploy). Players can then turn notifications on.
VAPID_PUBLIC_KEY
VAPID_PRIVATE_KEY
CRON_SECRET
Keep the private key and cron secret to yourself — paste them only into Vercel. Once players have turned notifications on, keep the same keys: new keys stop the old subscriptions from working.
